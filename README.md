# text2color

Дообучение BERT для определения цвета, который возникает в голове при чтении короткой зарисовки.

> «Солнце медленно опускается в море, по воде бежит дорожка света.» → **оранжевый**
> «Он хлопнул дверью так, что задрожали стёкла, и долго не мог успокоиться.» → **красный**

Учебный проект: классификация текста на русском языке с помощью предобученного трансформера-энкодера. Весь путь — от токенизатора до анализа ошибок — пошагово разобран в ноутбуке [`text2color.ipynb`](text2color.ipynb).

## Задача

По зарисовке из 1–2 предложений предсказать один из 10 цветов:

**красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый, коричневый, белый, серый**

Зарисовки двух типов:

- **сцены** — цвет следует из описанных предметов: клубника → красный, туман → серый;
- **эмоции** — цвет задаётся чувством по фиксированной схеме:

| Эмоция | Цвет |
|---|---|
| злость, раздражение | красный |
| любовь, нежность | оранжевый |
| радость, восторг | жёлтый |
| надежда, новое начало | зелёный |
| грусть, печаль | голубой |
| спокойствие, умиротворение | синий |
| тайна, мечтательность | фиолетовый |
| уют, ностальгия | коричневый |
| лёгкость, облегчение | белый |
| скука, апатия | серый |

## Данные

[`data/data.csv`](data/data.csv) — 1500 зарисовок, по 150 на цвет, примерно поровну сцен и эмоций. Колонки: `text`, `color`, `type`.

Датасет синтетический: 10 первых примеров написаны вручную, остальные сгенерированы LLM по описанию задачи и проверены на дубликаты и прямые упоминания цветов.

Разбиение 70/15/15 на train / validation / test со стратификацией по паре «цвет + тип».

## Модель и обучение

- **Модель:** [`ai-forever/ruBert-base`](https://huggingface.co/ai-forever/ruBert-base) — русский BERT, 12 энкодер-блоков, ~178M параметров.
- **Голова:** `AutoModelForSequenceClassification` добавляет поверх BERT линейный слой 768 → 10, инициализированный случайно.
- **Обучение:** `Trainer` из `transformers`, lr `2e-5`, batch 16, weight decay 0.01, до 10 эпох. Лучшая эпоха выбирается по validation loss (`load_best_model_at_end`), тест используется один раз в конце.
- **Время:** ~80 секунд на RTX 4060.

## Результаты

| | Accuracy |
|---|---|
| случайное угадывание | 10% |
| модель до обучения | 9% |
| **после обучения (test)** | **66%** |

| Выборка | Accuracy |
|---|---|
| train | 99.9% |
| validation | 64.6% |
| test | 66.2% |

Лучшая эпоха — 7-я. Дальше training loss продолжает падать, а validation loss растёт: модель начинает переобучаться.

### Сцены и эмоции

| Тип | Accuracy на test |
|---|---|
| сцены | 48% |
| эмоции | 86% |

Неожиданный результат: изначально казалось, что эмоции будут сложнее, потому что связь «любовь → оранжевый» условная. Вышло наоборот. Возможные причины:

- **Эмоции проще по форме.** Каждая эмоция описывается узнаваемым набором слов («вскочил», «кричал» — злость), и модель находит эти маркеры. Свою роль может играть однообразие сгенерированных текстов.
- **Сцены требуют знаний о мире.** Чтобы понять, что сапфир синий, а зола серая, нужно знать цвета предметов. BERT учился только на тексте и знает цвета вещей лишь настолько, насколько о них пишут.

Хуже всего модель справляется со сценами коричневого, белого и жёлтого цветов (25–33%). Среди эмоций выделяется грусть → голубой (36%). Самая частая ошибка — голубой, принятый за коричневый.

## Выводы

- Дообучение BERT на 1000 примерах за полторы минуты даёт 66% accuracy на 10 классах при случайном уровне в 10%.
- Модель почти идеально запоминает train (99.9%) — признак переобучения. Ранняя остановка по validation помогает, но главный рычаг — данные.
- Разбивка по типам показала то, чего не видно по одной общей accuracy: проблема в сценах, а не в эмоциях.

## Что можно улучшить

- больше и разнообразнее сцен, особенно для коричневого, белого и жёлтого;
- проверить разметку вручную: часть синтетических меток спорна;
- оценить «человеческий потолок»: разметить часть теста самому и сравнить с моделью;
- кросс-валидация вместо одного разбиения — на 225 тестовых примерах один пример ≈ 0.4%;
- сравнить с `cointegrated/rubert-tiny2` и подобрать learning rate по validation.

## Запуск

```bash
git clone https://github.com/ahruslan17/text2color.git
cd text2color
uv sync
uv run jupyter lab
```

Откройте `text2color.ipynb` и выполните **Run → Run All Cells**. Нужна видеокарта с CUDA, хотя на CPU обучение тоже заработает, только медленнее.

## Что внутри ноутбука

1. Данные и словарь меток
2. Разбиение на train / validation / test
3. Токенизатор: subword-токены, служебные `[CLS]`/`[SEP]`, сравнение токенизаторов (английский BERT, мультиязычный BERT, rubert-tiny2, ruBert-base, GPT-4), padding и attention mask
4. Модель изнутри: эмбеддинги, энкодер-блоки, pooler, головы MLM / NSP и новая голова классификации
5. Предсказание до обучения — точка отсчёта
6. Обучение через `Trainer` с выбором лучшей эпохи по validation
7. Диагностика: train vs validation vs test, матрица ошибок, сцены и эмоции отдельно, примеры ошибок
